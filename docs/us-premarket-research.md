# 美股盘前信号日研究（本地实现草案）

此路径仅在美股分析使用早于运行日的冻结信号日时启用，不读取账户、不生成订单。`analysis_date` 对应交易所完整收盘日线；开盘后的 15/30 分钟确认由独立流程负责。原模型评分保留在内部审计 `raw_model_score`，报告技术评分取原有 `StockTrendAnalyzer` 的 `signal_score`，评分权重及阈值未改；技术文字逐项引用该次计算的 `score_components`。

## 条件价格计划

使用信号日及之前去重日线计算 MA5/10/20、Wilder ATR14（TR 含跳空），以及两侧各两根已完成日线确认的高低点；信号日最高价与近 20 日高低点亦作为压力／支撑参考。美元价格按 0.01 报价单位暂算；低于 1 美元的证券因最小报价单位未核实而保持观察。

- MA5＞MA10＞MA20：理想点为 MA5 浅回踩，次优点为 MA10 深回踩。入场区间为均线 ±0.25 ATR；止损在区间下方最近结构支撑再减 0.25 ATR。
- 非多头：MA5 为收复观察位，不取得盘前入场资格；次优为 20 日高点、MA10、MA20 中最高压力的突破—回踩情景。入场区间为压力＋0.1 ATR 至压力＋0.5 ATR；盘前止损仅为压力－0.5 ATR 的参考，开盘后还需用回踩低点复核。
- 目标一、二依次取入场区间上方的已确认压力，减 0.1 ATR；突破情景缺少第二压力时，只有存在 20 日基底才使用整理区间高度形成测量目标。没有结构依据就写“观察”，不强填。
- 逐情景检查 `止损 < 入场下沿 <= 入场上沿 < 目标一 < 目标二`；回踩区间不得跨越未突破的压力。没有最低收益风险倍数硬门槛，费用与滑点不作为本版入围条件。整套计划仅是待开盘复核／观察，新增计划股数恒为 0。

## 资讯、报告与限制

盘前新闻可晚于信号日收盘，但不得晚于本轮运行截止。新闻需要来源名称、链接和发布时间；每只股票最多尝试核对三条可信公共域名的来源页面发布时间，成功时以来源页面时间校正搜索结果。带时区的完整搜索时间只能核验元数据，早于运行日的日期-only 信息只算部分核实，同日日期-only 在来源页面无精确时间时不能证明盘前已发布。最终报告只给核验结论，详细条目留在审计。财务报告期间不等于披露时间；若缺披露时间和原始来源链接、或来源页面未核到精确时间，不显示具体业绩数值。来源时间核验不等于对原文事实逐条核验。

报告使用信号日收盘标题及 USD，量能评分状态与昨量比分列。数据块可用性取分析上下文真实 `overall_score`，不得写死为 97。旧的单组 `sniper_points` 仅保存两个参考位和情景提示；准确区间、止损、双目标与状态在 `battle_plan.price_plan`。共享开盘 handoff 的成本及退出比例契约另有要求，不能把本报告的“待开盘复核”直接等同于共享校验器已通过。
